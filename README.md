# Juegos de Memoria

Dos actividades web para psicopedagogía, sin instalación: se abren en el navegador (celular, tablet o computador).

| Actividad | Público | Qué trabaja |
|---|---|---|
| **Ya lo conozco** | Niños y niñas | Memoria implícita (*priming*): los animales vistos al inicio deberían reconocerse más rápido cuando aparecen como silueta o tapados. |
| **La historia escondida** | Personas mayores | Memoria episódica: observar 4 viñetas, escuchar la historia, guardarlas y recordar quién, dónde, qué pasó primero y al final. |

Cada juego sigue las fases **Inicio · Desarrollo · Cierre** y al terminar muestra un panel *“Para quien guía la actividad”* con los resultados.

## Uso local

Abrir `index.html` en el navegador, o servir la carpeta:

```bash
python3 -m http.server 8000
```

HTML, CSS y JavaScript sin dependencias; las imágenes son emojis.
